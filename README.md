# mirra-email-assets

Public image hosting for Mirra Professional email campaigns, served by GitHub Pages.

- One folder per campaign. Never overwrite or delete files: emails stay in inboxes for years and their images must keep loading.
- Base URL: https://lucasn3ff4.github.io/mirra-email-assets/<campaign>/<file>
- Managed from the Mirra_Website repo (`email/`). Do not upload unreleased products here.
